# Skill: query

Responde perguntas usando o conteúdo de `concepts/`.

## Como usar

1. Leia `concepts/index.md` primeiro
2. Abra as páginas relevantes
3. Responda com citação das páginas
4. Se a resposta for útil, pergunte se deve ser gravada como nova página em `concepts/`

## Regras

- Prefira a wiki a buscar em `raw/`
- Não invente informação que não esteja na wiki
- Registre a consulta em `concepts/log.md` com o formato `## [YYYY-MM-DD] query | título`
