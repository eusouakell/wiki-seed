# Skill: site

Preenche `site/index.html` com o que a wiki já sabe. O site é um exemplo: serve para ver se o contexto está utilizável.

## O que fazer

1. Leia `concepts/index.md` e `concepts/overview.md`
2. Abra só as páginas de pessoa e de projetos que o índice aponta
3. Edite `site/index.html`: troque o nome, a frase de apresentação, os cartões de projetos e o "Sobre". Mantenha o estilo e a estrutura da página
4. Use só o que está na wiki. Não invente cargos, números ou datas. Se faltar algo, deixe o texto de exemplo e diga o que faltou
5. Registre no log: `## [YYYY-MM-DD] site | atualizado a partir da wiki`

## Regras

- Não publique. Ativar GitHub Pages ou fazer push é decisão da pessoa
- Não inclua contato, telefone, endereço ou outro dado pessoal que a pessoa não tenha pedido para mostrar
- Não apague nem mova arquivos
